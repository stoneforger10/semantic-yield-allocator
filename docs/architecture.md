# Consensus boundary and novelty audit

Client owns criterion selection and corpus curation, neither of which is evidence
that an external event occurred. External HTTPS source owns bytes. The contract
owns exact acquired-byte identity, bounded schema, selection schedule, semantic
label consensus, counts, trial budget and immutable observation chain.

`register -> activate -> (choose -> refetch -> classify -> compare -> learn)*`

Two labels for identical stored scheduler state can produce different next arms:
after arm zero HIT and arm one MISS, arm zero gets the next trial; reversing those
labels chooses arm one. Those labels come from independent AI calls on fetched
passage contents, not stored edge checks. See the paired direct tests and live
proof matrix. Deterministic allocation enforces consequences; it does not replace AI.

No owner-controlled graph, propose/finalize flow, certificate issuance/consumption,
or domain-renamed storage. One representative mechanism is published. Related work
may already exist; no claim of globally unique invention is made.

Observation identity includes experiment key and trial. The key includes contract
and authenticated creator. Before-statistics are deep-copied before updates; roots
bind them and the resulting statistics. Replay cannot change the record or spend
the same passage twice. Complete corpus pinning freezes the sequence and avoids a
caller supplying a different passage once the next arm becomes known.

Activation failure is terminal rather than silently accepting a weaker corpus.
Step acquisition failure halts without a reward. A new experiment with a new
name is necessary to try another artifact; old history remains available.
